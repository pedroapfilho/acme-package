## A deliberately small example domain

The template uses `createStore` in `@acme/core` and `useStore` in `@acme/react` to show the split
most libraries grow into: a platform-neutral engine with zero dependencies, plus a thin framework
binding that declares the framework as a peer. Replace that example with your own domain and keep
the rest of the system intact.
